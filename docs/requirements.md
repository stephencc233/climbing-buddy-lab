# climbing-buddy-lab 需求（练习版 v0.1）

## 1. 问题陈述
- 谁：抱石 V3+ / 先锋 5.12a+，每周室内训练 ≥ 2 次的攀岩者
- 场景：室内训练中，完成一条线后的休息间隙，手边有手机
- 困难：几个月停在瓶颈期，说不清哪类线在进步、哪类在退步，不知道训练是否有效
- 现在怎么凑合：不记录，凭体感判断进步

## 2. 假设
- H1（成本）：如果每条线的记录耗时 ≤ 20 秒，那么目标用户会坚持记录。
  判定：连续 4 周，“当次尝试过的线路全部记录”的训练次数 / 实际训练次数 ≥ 80%
- H2（价值）：如果能按周看到各线路类型的完攀率变化，那么目标用户能据此调整训练。
  判定：4 周内至少 1 次因统计结果改变了训练安排

## 3. 范围
- Must
  1. 记录一条线：难度、类型（多选）、角度、尝试次数（默认 1）、是否完攀；日期自动记录
  2. 按周查看完攀率：按难度、类型、角度三者之一筛选
- Should：线路自我投入度（3 级）；多周对比表；各类型尝试次数统计表；删除最近一条记录
- Could：岩馆选择；线路笔记心得；组合筛选；补录指定日期
- Won't（本版）：App、云端、数据导出、拍照记录线路；先锋难度
- 待确认：产品形态（命令行 vs 网页）；lab 中 `send_rate` 的口径（U04 核对）

## 4. 约定
- 难度：V0–V17
- 线路类型（多选，至少 1 个）：协调、动态、指力、平衡、技巧、耐力、能力
  - 能力线：考验力量、肩部等核心能力的线路风格
- 线路角度（单选）：大仰角、小仰角、直壁、slab
- 多选统计：一条线计入每个所选类型
- 周：ISO 8601 周（周一至周日），显示时附日期范围
- 完攀率 = 完攀线路条数 / 记录线路条数，百分比保留 1 位小数
- 筛选结果为空时显示“本周未进行该<难度/类型/角度>攀爬”，不显示 0%
- 记录只存日期，不存时刻

## 5. 非功能需求
- NFR1 每条记录最多 5 个字段，全部从列表选择或带有默认值，无需自由文本输入

## 6. 用户故事与验收标准

### 故事 1：记录一条线
作为目标用户，我想要在完成一条线后快速记下难度、类型、角度、尝试次数和是否完攀，以便积累可统计的训练数据。

- AC1.1 Given 今天是 2026-10-09 When 记录 V4、指力、小仰角、尝试 3 次、完攀 是 Then 新增 1 条记录，各字段与输入一致，日期为 2026-10-09
- AC1.2 Given 已有 5 条记录 When 记录时不填尝试次数 Then 保存成功，尝试次数为 1，记录总数为 6
- AC1.3 Given 已有 5 条记录 When 尝试次数填 0 或非整数 Then 拒绝保存并提示“尝试次数须为 ≥ 1 的整数”，记录总数仍为 5
- AC1.4 Given 已有 5 条记录 When 难度、角度、是否完攀任一未填，或类型一个都没选 Then 拒绝保存并提示缺少的字段，记录总数仍为 5
- AC1.5 Given 已保存 1 条记录 When 退出程序后重新启动并查询 Then 该记录仍存在且字段不变

### 故事 2：按难度查看某周完攀率
作为目标用户，我想要查看某一周某个难度的完攀率，以便判断自己在这个难度上是否进步。

- AC2.1 Given 2026 年第 41 周有 4 条 V4 记录，其中 3 条完攀 When 查看第 41 周 V4 Then 显示 75.0%，并附日期范围 10-05 至 10-11
- AC2.2 Given 2026-10-11 和 2026-10-12 各有 1 条 V4 记录 When 查看第 41 周 V4 Then 只统计 10-11 那 1 条
- AC2.3 Given 第 41 周有 3 条 V5 记录，其中 2 条完攀 When 查看第 41 周 V5 Then 显示 66.7%

### 故事 3：按类型或角度查看某周完攀率
作为目标用户，我想要查看某一周某个线路类型或角度的完攀率，以便发现哪类线在退步，并据此调整训练。

- AC3.1 Given 第 41 周有 5 条“动态”记录，其中 2 条完攀 When 查看第 41 周“动态” Then 显示 40.0%
- AC3.2 Given 第 41 周没有任何“平衡”记录 When 查看第 41 周“平衡” Then 显示“本周未进行该类型攀爬”，不显示 0%，也不报错
- AC3.3 Given 第 41 周只有 1 条记录，类型为“动态 + 协调”，已完攀 When 分别查看“动态”和“协调” Then 两者均显示 100.0%
